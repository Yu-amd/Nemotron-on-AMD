**Version split is a first-class caveat.** Wheel selection must follow **HIP 7.14**, not the 7.0.2 wrapper file. AMD docs (checked 2026-08-15) publish:

```text
pip install --index-url https://repo.amd.com/rocm/whl-multi-arch/ \
  "torch[device-gfx942]==2.12.0+rocm7.14.0"
```

Do not install CUDA wheels. Do not upgrade host ROCm/kernel to “simplify” this split.

## What we will run here first

`nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16` on one GPU.

Raw BF16 weights ~60 GB. Remaining ~132 GB is **not** “free KV cache”; framework + SSM/MoE state consume unknown amounts. Short context is still the first test.

## Validation vs theory

Environment collection does **not** by itself make Nano **Runs**. The Transformers, vLLM serve, and characterization artifacts above do. They do **not** make Nano Validated, Optimized, Production-ready, or a long-context claim. This node is an SR-IOV VF, not a proven equivalent of a full OAM device. AMD’s ROCm 7.14 vLLM path here is Docker/Python 3.14; the Transformers venv remains Python 3.12.
