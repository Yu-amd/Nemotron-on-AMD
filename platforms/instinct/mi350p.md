# AMD Instinct MI350P

**Status: NOT YET VALIDATED.** No MI350P is attached to this project.

PCIe CDNA4 card. GPU-to-GPU over PCIe is **not** treated as an optimized scale-up path in this project. If weights do not fit **one** 144 GB card, Fit is **doesn't fit** (never 2×/4×/8×). Do not copy MI350X OAM results onto this SKU. Do not treat MXFP4 hardware as NVFP4.
